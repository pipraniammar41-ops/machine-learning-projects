# 📱 Social Network Ads Prediction

A Machine Learning classification project focused on predicting whether
a user is likely to purchase a product based on demographic and salary
information.

## 🎯 Objective

The goal of this project is to predict whether a user will purchase a
product after seeing a social network advertisement.

## 📊 Project Workflow

- Data loading and understanding
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Categorical encoding using LabelEncoder
- Feature selection
- Train-test split
- Feature scaling using StandardScaler
- Model training and testing
- Confusion matrix analysis
- Classification report
- Model comparison

## 🤖 Models Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier

## 📈 Model Results

| Model | Accuracy |
|---|---:|
| Logistic Regression | 88.75% |
| Logistic Regression (Scaled) | 86.25% |
| KNN | 72.50% |
| KNN (Scaled) | 95.00% |
| Decision Tree | 87.50% |

The KNN model with feature scaling achieved **95% accuracy** on the
test dataset.
