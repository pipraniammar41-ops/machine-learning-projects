# 📉 Customer Churn Prediction

A Machine Learning classification project focused on predicting whether a
customer is likely to churn based on customer demographics, subscription
details, service usage, and billing information.

## 🎯 Objective

The goal of this project is to identify customers who are likely to leave
the service and understand the factors associated with customer churn.

## 📊 Project Workflow

- Data loading and understanding
- Exploratory Data Analysis (EDA)
- Missing value detection and handling
- Duplicate and data quality checks
- Numerical and categorical feature analysis
- Outlier analysis
- Correlation analysis
- Feature engineering
- Feature selection
- Target encoding
- Train-test split
- Feature scaling
- Model training and testing
- Model evaluation
- Model comparison and improvement

## 🤖 Models Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes

## 🧠 Key Concepts Practiced

- Classification
- EDA
- Data Cleaning
- Feature Engineering

## 📌 Project Outcome

The project demonstrates an end-to-end classification workflow, from
understanding and preprocessing raw customer data to training, evaluating,
comparing, and improving Machine Learning models for churn prediction.
